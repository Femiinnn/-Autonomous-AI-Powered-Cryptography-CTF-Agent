How It Works
Step 01
🔍
Classify & Plan
Llama-3 reads the challenge parameters, identifies the crypto category, pinpoints the mathematical flaw, and selects the optimal attack vector.
Step 02
⚙️
Generate Exploit
The model writes a standalone Python or SageMath exploit script. If a previous attempt failed, the error is injected as feedback for self-correction.
Step 03
🐳
Execute in Sandbox
Code runs inside an ephemeral Docker container (SageMath + gmpy2 + pwntools) with no network, memory limits, and a strict 30-second timeout.
Step 04
🚩
Capture the Flag
The agent scans stdout for flag{…} patterns. On failure, it retries up to 4 times, re-hypothesizing the attack if needed.
